# VIRTUAL AV LAB: หน้าสำรวจและตรวจตำแหน่งพอร์ต

วันที่ 23 ตุลาคม 2026

## ผลลัพธ์

index.html เป็นหน้าสำรวจอุปกรณ์ 3 มิติสำหรับรายวิชาการใช้และบำรุงรักษาเครื่องมือทางเทคโนโลยีการศึกษา เลือกอุปกรณ์ทั้ง 5 ตัว หมุน/ซูม/เลื่อน เลือกชื่อพอร์ตหรือคลิกบนหัวต่อจริงเพื่อดูหน้าที่ IN/OUT เงื่อนไขและเอกสารอ้างอิง ไม่มีการเรียก AI API หรือส่งเอกสารไปวิเคราะห์ภายนอก

ทะเบียนตำแหน่งใหม่อยู่ใน data/model-mappings.json แยกจากฐานข้อมูลสเปก data/port-catalog.json จับคู่ geometry ที่อ้างด้วย node index และ SHA-256 ของ glTF โดยใช้เฉพาะ vertices ที่ indices ของชิ้นส่วนนั้นอ้างถึง ไม่ใช้ accessor bounds ของทั้งเครื่องซ้ำเป็นตำแหน่งพอร์ต

| อุปกรณ์ | รายการในฐานข้อมูล | ตำแหน่งที่จัดเตรียมบนโมเดล |
|---|---:|---:|
| Dell G7 7588 | 6 | 6 |
| Epson EB-2165W | 16 | 16 |
| Sony UBP-X700 | 6 | 6 |
| Sony KDL-40W650D | 12 | 12 |
| Vertex D-1420HW | 18 | 18 |
| รวม | 58 | 58 |

Epson ลงบัญชี USB-A เพียงช่องเดียว ตัดรายการ USB-A for wireless LAN module แยกออกตามคำสั่งผู้ใช้ โดยเก็บที่มาของข้อแก้ไขไว้ใน ref/PORT_CORRECTIONS_2026-10-23.md ส่วน TV ใช้ PDF ใหม่หน้า 28/38 แทนการเดาจำนวน USB จากโมเดล

อุปกรณ์ทั้ง 5 มี user_acceptance=accepted จากคำยืนยันผู้ใช้วันที่ 23 ตุลาคม 2026 รวม 58 จุด พิกัดเดิมคงไว้ บันทึกการตรวจรับใน ref/PORT_ACCEPTANCE_2026-10-23.md สถานะยอมรับของผู้ใช้ไม่สามารถนำเข้าจาก JSON ได้โดยอัตโนมัติ

สถานะ reviewed ในทะเบียนหมายถึงตรวจการจับคู่ฉลาก/ชิ้นส่วนและจุดอ้างอิงจาก geometry ของโมเดล ไม่ใช่การทดสอบอุปกรณ์จริงหรือการยืนยันความสามารถเพิ่มเติม จุดกึ่งกลางด้านหน้าของขอบเขตหัวต่อเป็นจุดตั้งต้นสำหรับเสียบสาย จึงปรับให้ตรงผิวหรือศูนย์กลางช่องตามความต้องการของกิจกรรมได้ในโหมดอาจารย์

VGA สามช่องด้านหลัง Vertex อยู่ใน mesh เดียวกัน จึงแยกขอบเขตตามช่องและใช้ระยะจากจุดคลิกเลือกช่องใกล้ที่สุด ไม่ตีความว่า mesh เดียวเท่ากับพอร์ตเดียว

## วิธีใช้

1. เลือกอุปกรณ์จากแถบซ้าย
2. เลือกชื่อพอร์ตเพื่อซูมดู หรือคลิกบนช่องต่อของโมเดล
3. ดูหน้าที่และเปิดเอกสารอ้างอิงจากแถบรายละเอียด
4. ใช้ “ดูแผงพอร์ตโดยรอบ” เพื่อเทียบทิศทางกับช่องข้างเคียง
5. หากต้องปรับตำแหน่ง เปิดแท็บ “ตรวจตำแหน่ง” และเปิดโหมดปรับเทียบ เลือกชื่อพอร์ตแล้วคลิกผิวหน้าหัวต่อ กด “ใช้จุดที่คลิก” และ “ยืนยันตำแหน่งที่เลือก”
6. ผลตรวจเฉพาะเครื่องเก็บใน localStorage ของเบราว์เซอร์ ส่งออก JSON แล้วนำเข้าบนเครื่องอื่นได้ ข้อมูลนำเข้าไม่เปลี่ยนหน้าที่พอร์ตหรือข้อเท็จจริงในฐานข้อมูลสเปก

การคืนค่าจะล้างเฉพาะผลปรับเทียบเฉพาะพอร์ตในเบราว์เซอร์นั้น ไม่ลบตำแหน่งตั้งต้นใน repository

## การแสดงผลและการตรวจสอบ

Three.js r128, GLTFLoader และ OrbitControls เก็บใน vendor พร้อมใบอนุญาต MIT ไม่ต้องโหลด CDN ขณะใช้งาน หาก WebGL ใช้ไม่ได้ จะใช้ Canvas แสดง geometry เดิมด้วยมุมกล้องเดียวกัน หมุน/ซูม/คลิก/ปรับเทียบได้ แต่โหมดสำรองไม่แสดง texture และเงาเหมือน WebGL

ทดสอบผ่านเบราว์เซอร์จริงในโหมดสำรอง: โหลดครบ 5 โมเดล, เลือกชื่อพอร์ต, เปลี่ยนมุมมอง, ค้นหา, คลิก VGA ช่องที่ 2/3 ที่ใช้ mesh ร่วมกัน, บันทึกจุด/ยืนยัน, เก็บค่าหลัง reload และส่งออก–นำเข้าผลตรวจกลับมาได้

เบราว์เซอร์ทดสอบไม่สามารถสร้าง WebGL context ได้ จึงยังไม่ได้ตรวจภาพ WebGL บน GPU จริง ส่วนทั้งสองโหมดใช้ geometry กล้องและ raycaster ชุดเดียวกัน ไม่ได้สร้างโมเดลภาพสำรองแยก

ชุดทดสอบครอบคลุมกฎการเชื่อมต่อเดิม และการตรวจนำเข้า: หมายเลขชิ้นส่วน, asset hash, เวกเตอร์ normal, พิกัดไม่เป็นตัวเลข, ขอบเขตกลับด้าน, พอร์ตไม่รู้จัก, การคงขอบเขตของ mesh ร่วม และป้องกันผลปรับเทียบเขียนทับความสามารถพอร์ต

```sh
python scripts/build_model_mappings.py
node --test tests/*.test.mjs
```

scripts/build_ref_catalog.py ตรวจ SHA ของ ref ที่ผ่านการทบทวนไว้ หาก ref เปลี่ยน ต้องทบทวนไฟล์ใหม่นั้นก่อน ไม่แก้ hash ให้ผ่านโดยอัตโนมัติ

## ขอบเขตระยะนี้

พร้อมใช้สำรวจและตรวจตำแหน่งพอร์ต และยูสเคส 2 รวม 18 โจทย์: 2 อุปกรณ์ 4 ข้อ, 3 อุปกรณ์ 10 ข้อ, 4 อุปกรณ์ 4 ข้อ เลือกพอร์ต/สายแต่ละช่วง ตั้ง SOURCE / Input ตรวจแหล่งภาพและสลับสองแหล่งโดยไม่ถอดสาย พร้อมผังอัตโนมัติ ผลภาพจำลอง และประวัติรหัสโจทย์สำเร็จในเบราว์เซอร์ ดู docs/CONNECTION_LESSON_TH.md ยังไม่มีการลากสายอิสระ เครื่องมือเขียนผังเอง แบบฝึกให้คะแนน หรือบัญชีผู้ใช้

## ทบทวน Sony TV จาก PDF ใหม่

PDF หน้า 28 ให้ภาพแผงพอร์ต หน้า 38 ให้ชนิดหัวต่อและรูปแบบอินพุต: HDMI 1 หลังรองรับ ARC; HDMI 2 ด้านข้าง; USB 1/2 ด้านข้าง; AUDIO OUT/หูฟังด้านข้าง; Optical OUT หลัง; VIDEO IN, Audio L/MONO และ R, LAN, RF และ DC IN ที่แผงล่าง รวม 12 ช่องรวมไฟเลี้ยง

| รายการ | GLTF node | ผลเทียบ |
|---|---:|---|
| HDMI IN 1 (ARC) | 109 | หลัง ใต้ Optical |
| HDMI IN 2 | 131 | แผงข้าง ใต้ USB |
| Optical OUT | 56 | หลัง เหนือ HDMI 1 |
| USB 1 / USB 2 | 163 / 96 | แยกสองช่องด้านข้าง |
| Audio OUT/หูฟัง | 153 | ด้านข้าง ใต้ HDMI 2 |
| Composite VIDEO IN | 30 | RCA แผงล่าง ด้าน VIDEO |
| Audio L (MONO) / R | 32 / 34 | ตามตำแหน่งฉลากแผงล่าง ไม่ใช้สี geometry ตัดสิน |
| LAN | 7 | ซ้ายของกลุ่ม AV เมื่อดูแผงจากด้านหลัง |
| RF | 36 | ตามฉลากสายอากาศ ไม่ยืนยันมาตรฐานหัว RF จาก geometry |
| DC IN 19.5 V | 57 | ตามฉลาก DC IN ที่แผงล่าง |

แบบจำลองเป็นตัวแทนเครื่อง ไม่ใช้สีของวัสดุหัว RCA ยืนยัน L/R เพราะสี geometry กับฉลากแผงอาจไม่ตรงกัน ไม่เพิ่ม HDD REC ซึ่งคู่มือจำกัดประเทศออสเตรเลีย/นิวซีแลนด์ และไม่เพิ่ม Component จากภาพเปรียบเทียบสายทั่วไปหน้า 28

ช่อง MIC ของ Vertex แสดง Phone 1/4 นิ้ว (6.35 มม.) ตามผู้ใช้ยืนยัน พร้อมแหล่งข้อมูลแยกจากคู่มือ ไม่สมมติจำนวนหน้าสัมผัส TS/TRS

## โต๊ะทดลองเชื่อมต่อภาพ (UX/UI)

ควบคุมจากอุปกรณ์บนผังโดยตรง: เปิด/ปิด ส่งภาพ เล่นสื่อ SOURCE และ Input พร้อมปุ่มอินพุตพอร์ตและเอาท์พุตพอร์ตแยกกัน ครอบคลุมช่องจริง 58 ช่อง เปิด GLTF ดูตำแหน่งตามกลุ่มทิศทางได้ คลิกเส้นหรือหมายเลขสายมีเพียง Dropdown เลือกสาย 17 ชนิด ไม่มีช่องเลือกพอร์ตซ้ำ ระบบตรวจเชื่อมอัตโนมัติเมื่อเลือกพอร์ตและสายครบ แผงขวาเหลือเป้าหมายและผลทดลอง แถบขั้นตอนเป็นตัวบอกความคืบหน้า ไม่มีการบังคับลำดับ มีคำแนะนำไปยังจุดตรวจ ย้อนการกระทำ และยืนยันล้างโจทย์

คง 18 โจทย์ สเปกและตำแหน่งพอร์ตที่ตรวจรับ และข้อจำกัด Source Switch ของ Vertex เส้นทางสายที่เพิ่มยังไม่สร้างความสามารถหรือผลคะแนนจากข้อสันนิษฐาน ดู docs/CONNECTION_LESSON_TH.md
