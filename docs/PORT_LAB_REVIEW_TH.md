# AV Port Lab: หน้าสำรวจและตรวจตำแหน่งพอร์ต

วันที่ 23 ตุลาคม 2026

## ผลลัพธ์

index.html เป็นหน้าสำรวจอุปกรณ์ 3 มิติสำหรับรายวิชาการใช้และบำรุงรักษาเครื่องมือทางเทคโนโลยีการศึกษา เลือกอุปกรณ์ทั้ง 5 ตัว หมุน/ซูม/เลื่อน เลือกชื่อพอร์ตหรือคลิกบนหัวต่อจริงเพื่อดูหน้าที่ IN/OUT เงื่อนไขและเอกสารอ้างอิง ไม่มีการเรียก AI API หรือส่งเอกสารไปวิเคราะห์ภายนอก

ทะเบียนตำแหน่งใหม่อยู่ใน data/model-mappings.json แยกจากฐานข้อมูลสเปก data/port-catalog.json จับคู่ geometry ที่อ้างด้วย node index และ SHA-256 ของ glTF โดยใช้เฉพาะ vertices ที่ indices ของชิ้นส่วนนั้นอ้างถึง ไม่ใช้ accessor bounds ของทั้งเครื่องซ้ำเป็นตำแหน่งพอร์ต

| อุปกรณ์ | รายการในฐานข้อมูล | ตำแหน่งที่จัดเตรียมบนโมเดล |
|---|---:|---:|
| Dell G7 7588 | 6 | 6 |
| Epson EB-2165W | 17 | 16 |
| Sony UBP-X700 | 6 | 6 |
| Sony KDL-40W650D | 7 | 7 |
| Vertex D-1420HW | 18 | 18 |
| รวม | 54 | 53 |

ช่อง USB สำหรับโมดูล Wireless LAN ภายในฝาครอบ Epson ยังไม่มีชิ้นส่วนหัวต่อแยกที่ระบุได้ในโมเดล จึงคงรายการสเปกและเอกสารไว้โดยไม่สร้างจุดสมมติ ไม่มีการรับรองว่า geometry เพิ่มเติมที่ไม่ได้อยู่ในรายการสเปกคือพอร์ตที่รุ่นจริงมี เช่น USB ของ TV ที่สเปกใน ref อ่านรายละเอียดไม่ครบ

สถานะ reviewed ในทะเบียนหมายถึงตรวจการจับคู่ฉลาก/ชิ้นส่วนและจุดอ้างอิงจาก geometry ของโมเดล ไม่ใช่การทดสอบอุปกรณ์จริงหรือการยืนยันความสามารถเพิ่มเติม จุดกึ่งกลางด้านหน้าของขอบเขตหัวต่อเป็นจุดตั้งต้นสำหรับเสียบสาย จึงปรับให้ตรงผิวหรือศูนย์กลางช่องตามความต้องการของกิจกรรมได้ในโหมดอาจารย์

VGA สามช่องด้านหลัง Vertex อยู่ใน mesh เดียวกัน จึงแยกขอบเขตตามช่องและใช้ระยะจากจุดคลิกเลือกช่องใกล้ที่สุด ไม่ตีความว่า mesh เดียวเท่ากับพอร์ตเดียว

## วิธีใช้

1. เลือกอุปกรณ์จากแถบซ้าย
2. เลือกชื่อพอร์ตเพื่อซูมดู หรือคลิกบนช่องต่อของโมเดล
3. ดูหน้าที่และเปิดเอกสารอ้างอิงจากแถบรายละเอียด
4. ใช้ “ดูแผงพอร์ตโดยรอบ” เพื่อเทียบทิศทางกับช่องข้างเคียง
5. หากต้องปรับตำแหน่ง เปิดแท็บ “ตรวจตำแหน่ง” และเปิดโหมดปรับเทียบ เลือกชื่อพอร์ตแล้วคลิกผิวหน้าหัวต่อ กด “ใช้จุดที่คลิก” และ “ยืนยันตำแหน่งที่เลือก”
6. ผลตรวจเฉพาะเครื่องเก็บใน localStorage ของเบราว์เซอร์ ส่งออก JSON แล้วนำเข้าบนเครื่องอื่นได้ ข้อมูลนำเข้าไม่เปลี่ยนหน้าที่พอร์ตหรือข้อเท็จจริงในฐานข้อมูลสเปก

การคืนค่าจะล้างเฉพาะผลปรับเทียบเฉพาะพอร์ตในเบราว์เซอร์นั้น ไม่ลบตำแหน่งตั้งต้นใน repository

## การแสดงผลและการตรวจสอบ

Three.js r128, GLTFLoader และ OrbitControls เก็บใน vendor พร้อมใบอนุญาต MIT ไม่ต้องโหลด CDN ขณะใช้งาน หาก WebGL ใช้ไม่ได้ จะใช้ Canvas แสดง geometry เดิมด้วยมุมกล้องเดียวกัน หมุน/ซูม/คลิก/ปรับเทียบได้ แต่โหมดสำรองไม่แสดง texture และเงาเหมือน WebGL

ทดสอบผ่านเบราว์เซอร์จริงในโหมดสำรอง: โหลดครบ 5 โมเดล, เลือกชื่อพอร์ต, เปลี่ยนมุมมอง, ค้นหา, คลิก VGA ช่องที่ 2/3 ที่ใช้ mesh ร่วมกัน, บันทึกจุด/ยืนยัน, เก็บค่าหลัง reload และส่งออก–นำเข้าผลตรวจกลับมาได้

เบราว์เซอร์ทดสอบไม่สามารถสร้าง WebGL context ได้ จึงยังไม่ได้ตรวจภาพ WebGL บน GPU จริง ส่วนทั้งสองโหมดใช้ geometry กล้องและ raycaster ชุดเดียวกัน ไม่ได้สร้างโมเดลภาพสำรองแยก

ชุดทดสอบครอบคลุมกฎการเชื่อมต่อเดิม และการตรวจนำเข้า: หมายเลขชิ้นส่วน, asset hash, เวกเตอร์ normal, พิกัดไม่เป็นตัวเลข, ขอบเขตกลับด้าน, พอร์ตไม่รู้จัก, การคงขอบเขตของ mesh ร่วม และป้องกันผลปรับเทียบเขียนทับความสามารถพอร์ต

```sh
python scripts/build_model_mappings.py
node --test tests/*.test.mjs
```

scripts/build_ref_catalog.py ตรวจ SHA ของ ref ที่ผ่านการทบทวนไว้ หาก ref เปลี่ยน ต้องทบทวนไฟล์ใหม่นั้นก่อน ไม่แก้ hash ให้ผ่านโดยอัตโนมัติ

## ขอบเขตระยะนี้

พร้อมใช้สำรวจและตรวจตำแหน่งพอร์ต ยังไม่มีการลากสายจำลองสัญญาณ การเขียนผัง แบบฝึกให้คะแนน หรือระบบบัญชีผู้ใช้ ยูสเคสส่วนดังกล่าวใช้ทะเบียนตำแหน่งและฐานข้อมูลสเปกชุดนี้พัฒนาต่อได้
