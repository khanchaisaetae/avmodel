# ยูสเคส 4 · ห้องเรียนหลายแหล่งภาพ

หน้า `classroom.html` ใช้ระบบผังและตัวควบคุมอุปกรณ์ร่วมกับยูสเคส 2 เพิ่มลำดับกิจกรรมการสอน ไม่เพิ่มการให้คะแนน

## เป้าหมาย

นิสิตเตรียมระบบภาพจาก Dell G7, กล้อง Vertex และ Sony Blu-ray ไปยังจอเดียว แล้วสลับ **สไลด์ → เอกสาร → วิดีโอ → กลับสไลด์** โดยไม่ถอดสาย อธิบายความต่างระหว่าง SOURCE ของอุปกรณ์กลางกับ Input ของจอได้

## โจทย์

| รหัส | เส้นทางที่ 1 | เส้นทางที่ 2 | ภาพเอกสาร |
| --- | --- | --- | --- |
| UC4-01 | Dell → Vertex → Epson | Blu-ray → Epson | กล้อง Vertex → Epson |
| UC4-02 | Dell → Vertex → Sony TV | Blu-ray → Sony TV | กล้อง Vertex → Sony TV |
| UC4-03 | Blu-ray → Vertex → Epson | Dell → Epson | กล้อง Vertex → Epson |
| UC4-04 | Blu-ray → Vertex → Sony TV | Dell → Sony TV | กล้อง Vertex → Sony TV |

แต่ละโจทย์มี 4 อุปกรณ์ 3 สายและจอเดียว กล้อง Vertex ใช้ HDMI OUT เส้นเดิมของทางผ่าน ไม่ได้เพิ่มสายออกหรืออุปกรณ์ Matrix ไม่มีโจทย์ 4-05 ถึง 4-10 ที่ยกเลิกไป

## วิธีฝึก

1. เลือกพอร์ต OUT และ IN จากตัวอุปกรณ์ เลือกชนิดสายจากเส้นในผัง
2. ต่อครบทั้ง 3 เส้น เปิดเครื่องและการส่งภาพ ตั้ง SOURCE / Input บนตัวอุปกรณ์
3. ทำตามลำดับด้านขวา กด “ยืนยันภาพช่วงนี้” เมื่อระบบตรวจภาพตรงเป้าหมาย
4. สลับ SOURCE ของ Vertex และ/หรือ Input ของจอเพื่อทำช่วงถัดไป โดยคงสายเดิม
5. ยืนยันครบ 4 ช่วง รวมการกลับสไลด์ แล้วทบทวนเหตุผลหรือดาวน์โหลดรายงาน JSON

การมองเห็นภาพอย่างเดียวไม่ยืนยันช่วงกิจกรรม ต้องกดยืนยันโดยผู้เรียน ไม่ข้ามขั้น ไม่ถือว่ากลับแหล่งภาพเดิมเท่ากับทำช่วงก่อนหน้าซ้ำ เปลี่ยนปลายสาย ชนิดสาย หรือสถานะเชื่อมต่อหลังยืนยันจะล้างหลักฐานและเริ่มลำดับใหม่ การเปลี่ยน SOURCE / Input หรือเปิดปิดเครื่องไม่ล้างประวัติลำดับ แต่ภาพปัจจุบันยังต้องถูกต้องก่อนยืนยัน

## กฎและขอบเขต

ใช้ `data/port-catalog.json`, `scenario-engine.mjs`, `connection-rules.mjs` และรายการสายร่วมกัน พอร์ต IN/OUT ยังเลือกสำรวจได้ครบ ไม่ซ่อนพอร์ตที่โจทย์ไม่ใช้ เส้นทางที่ยังไม่จำลองไม่ถูกตัดสินเป็นคำตอบผิดจากข้อมูลที่ไม่ครบ

Vertex ใช้ CAMERA หรือ HDMI IN → HDMI OUT ไม่แปลง RGB/VGA ไป HDMI ไม่แสดงพร้อมกันสองจอ Blu-ray HDMI OUT 2 ส่งเฉพาะเสียง ใช้ยืนยันภาพไม่ได้ รูปแบบ 1920×1080@60 และสาย HDMI ที่รองรับเป็นเงื่อนไขจำลองตามระบบเดิม ไม่เพิ่มเป็นสเปกอุปกรณ์จริง

## ข้อมูลผู้เรียน

- `av-port-lab.classroom-progress.v1`: รหัสโจทย์ที่เคยสำเร็จ แยกจากประวัติยูสเคส 2
- `av-port-lab.classroom-report.v1`: รายงานล่าสุดที่เปิดฝึก (เขียนทับเมื่อเปลี่ยนโจทย์) มีหลักฐานแต่ละช่วง เวลา พอร์ต สาย การตั้งค่า และเหตุผล ไม่มีคะแนน
- สายและลำดับขณะฝึกอยู่ในหน่วยความจำ เริ่มใหม่เมื่อโหลดหน้า ประวัติและรายงานล่าสุดเก็บในเบราว์เซอร์เครื่องนี้ ไม่มีบัญชีผู้เรียนหรือการส่งผลให้อาจารย์อัตโนมัติ
- ดาวน์โหลด JSON เพื่อเก็บสำเนาก่อนเปลี่ยนโจทย์หรือล้างข้อมูลเบราว์เซอร์ รายงานเป็นผลจำลอง ไม่ใช่หลักฐานทดสอบฮาร์ดแวร์จริง

## โครงสร้าง

- `classroom-catalog.mjs`: โจทย์และลำดับการสอน
- `classroom-model.mjs`: หลักฐานลำดับ ตรวจความคงเดิมของสาย ตรวจภาพ และสร้างรายงาน ไม่มี DOM
- `classroom-activity.mjs`: ส่วนขยายของหน้าฝึก สร้างแผงกิจกรรม เหตุผล การเก็บและดาวน์โหลดรายงาน
- `classroom.css`: รูปแบบลำดับและแผงรายงาน ใช้ CSS และตัวควบคุมอุปกรณ์ร่วมกับหน้าฝึกเดิม
- `mountConnectionLesson` รองรับ scenarios/progressKey/activity เพิ่มเติม ค่าเริ่มต้นยูสเคส 2 ยังคงเดิม

## ตรวจสอบ

`node --test tests/classroom.test.mjs` ตรวจครบ 4 โจทย์ 4 ช่วง ลำดับการยืนยัน การเปลี่ยนสาย ภาพผิดแหล่ง ช่องเสียงอย่างเดียว พอร์ตซ้ำ กฎ Vertex และรายงาน รวมถึงชุดทดสอบเดิมของทุกยูสเคส
