# ยูสเคส 4 · ทดลองเชื่อมต่อสามมิติ

เปิด `lab3d.html` เพื่อวางโมเดลอุปกรณ์ในฉากเดียว เลือกช่วงสาย คลิกพอร์ตบนโมเดล เลือกสาย และทดลองภาพตามโจทย์ 18 ข้อเดิม ใช้ `scenario-engine.mjs` และข้อมูลพอร์ต/ตำแหน่งที่ตรวจรับร่วมกัน ไม่มีคะแนน ยูสเคส 2 ยังคงการทำงานเดิม เพิ่มเฉพาะลิงก์กิจกรรมในเมนูหน้าแรก

## การใช้งาน

1. เลือกโจทย์ รอโหลดโมเดลเฉพาะอุปกรณ์ที่ใช้ พร้อมตรวจ SHA-256 ให้ตรงกับตำแหน่งพอร์ต
2. เลือกช่วงสาย แล้วคลิกปุ่มต้นทาง/ปลายทางเพื่อดูใกล้ หมุนดูหรือเลือกมุมด้านหน้า/หลัง/ซ้าย/ขวาได้
3. คลิกพื้นผิวพอร์ตจริงบนโมเดล อ้างอิงชิ้นส่วนและ anchor เดิม ไม่เพิ่มตำแหน่งพอร์ตใหม่ เลือกต้นทางแล้วกล้องไปปลายทาง
4. เลือกชนิดสาย สายสามมิติยึดปลายที่ anchor และยื่นตาม normal ของพอร์ต สีเขียวเข้มคือเชื่อมต่อผ่านกฎ สีอำพันคือยังตรวจไม่ผ่านหรือเส้นทางยังไม่จำลอง คลิกสายเพื่อกลับมาแก้ช่วงนั้นได้
5. คลิกชื่ออุปกรณ์บนฉากเพื่อเปิดปุ่มเปิด/ปิด ส่งภาพ SOURCE หรือ Input ของเครื่องนั้น
6. ตรวจภาพเมื่อพร้อม โจทย์หลายแหล่งภาพเลือกเป้าหมายและตรวจให้ครบทีละแหล่ง

มุมมอง “ทั้งระบบ” แสดงทุกเครื่อง รายการพอร์ตทั้งหมดในส่วนพับรองรับคีย์บอร์ดและการโฟกัสช่องต่อที่เล็ก ไม่มีการตัดพอร์ตที่ไม่ส่งภาพออกจากรายการ

## ขอบเขต

โมเดลและสายอยู่ในฉากสามมิติเดียวกัน สายเป็นรูปทรงจำลองเส้นทาง ไม่ใช่การจำลองหัวต่อ/กลศาสตร์การเสียบจริง ผลภาพแสดงในแผงผลภาพจำลอง ไม่แก้พื้นผิวจอในไฟล์ GLTF ใช้กฎสัญญาณเดิม รวมข้อจำกัด Source Switch ของ Vertex และสถานะยังไม่จำลองสำหรับอะแดปเตอร์ที่ไม่มีข้อมูลเพียงพอ

รองรับ WebGL และตัวแสดงผลสามมิติสำรองจากโมเดลเดิมเมื่อ WebGL ใช้ไม่ได้ โหมดสำรองไม่มี texture/shadow และอาจช้าในเครื่องที่มีทรัพยากรจำกัด เก็บโมเดลที่โหลดแล้วในหน่วยความจำเพื่อสลับโจทย์ ไม่ดาวน์โหลดซ้ำทุกครั้ง

## บันทึก

- คีย์ `av-port-lab.lab3d.v1.<taskId>` แยกจากงานยูสเคส 2 และ 3
- JSON schema `av-port-lab.lab3d`, version 1
- นำเข้าจะตรวจ task/อุปกรณ์/พอร์ต/สายและคำนวณการเชื่อมต่อใหม่ ไม่เชื่อ connected/complete จากไฟล์ ผลตรวจแหล่งภาพที่บันทึกไว้จะคืนเมื่อคำนวณเส้นทางนั้นซ้ำแล้วยังผ่าน
- สำเนาก่อนนำเข้าอยู่ใน `av-port-lab.lab3d.v1.import-backup`
- ข้อมูลเก็บในเบราว์เซอร์ ไม่มีการส่งออกไปเซิร์ฟเวอร์หรือบันทึกคะแนน

โมดูล: `lab3d-model.mjs` กฎการเลือกและไฟล์, `lab3d-scene.mjs` โหลดและจัดฉาก/คลิก/สาย, `lab3d-app.mjs` หน้าจอและการบันทึก, `lab3d.css` รูปแบบเฉพาะกิจกรรม

## จัดวางอุปกรณ์บนโต๊ะ

สลับปุ่ม “เชื่อมต่อ / จัดวางอุปกรณ์” เหนือฉาก ในโหมดจัดวาง ลากพื้นผิวตัวเครื่องด้วยเมาส์ซ้ายหรือสัมผัสเพื่อย้ายตามระนาบโต๊ะ X/Z ระดับ Y คงที่ เลื่อนล้อเพื่อซูม ลากพื้นว่างเพื่อหมุน ลากขวาเพื่อเลื่อนมุมมอง เครื่องที่เลือกมีวงเน้นฐานและป้ายเน้นสี ปลายสายและช่วงสายสามมิติปรับตามพอร์ตตลอดการลาก ไม่มีการแก้ตำแหน่งพอร์ตอ้างอิง

คลิกป้ายชื่อเครื่องแล้วกดลูกศรเพื่อย้ายทีละ 0.25 หน่วยบนโต๊ะได้ ปุ่ม “ย้อนตำแหน่ง” ย้อนเฉพาะการจัดวางได้ 30 ครั้ง และ “คืนตำแหน่งเริ่มต้น” ย้อนกลับได้เช่นกัน การย้อนตำแหน่งไม่คืนสถานะไฟ/สาย/แหล่งภาพ การย้ายไม่เปลี่ยนผลตรวจสัญญาณ

ตำแหน่งบันทึกใน `state.positions.<deviceId> = {x, z}` ของไฟล์เดิม version 1 และคีย์เดิม รองรับไฟล์เก่าที่ไม่มีตำแหน่งโดยจัดวางแบบเริ่มต้น ตำแหน่งต้องเป็นตัวเลข finite และอยู่ในขอบเขตโต๊ะ ±12 หน่วย ไม่มีการจำลองการชนเครื่องหรือแรงตึงสาย โหมด “ทั้งระบบ” คำนวณกล้องจากตำแหน่งจริงใหม่


## ลากหัวสายเสียบพอร์ต

เลือกชนิดสายก่อน ลากหัวต้นทาง/ปลายทางจากถาดไปที่พอร์ตบนโมเดล เมื่อใกล้พอร์ตภายใน 26 พิกเซลจะแสดงชื่อและสถานะพร้อมดูดเข้าตำแหน่งเมื่อตรวจหัวต่อผ่าน หัวสายมีรูปทรงสัญลักษณ์แยก HDMI, VGA, หัวกลมและหัวชนิดอื่น (ไม่ได้จำลองรายละเอียดเขี้ยวล็อกหรือหน้าสัมผัสจริง) สายที่เสียบเพียงด้านเดียวแสดงอีกหัววางข้างเครื่อง ยังไม่เป็นเส้นทางสัญญาณครบ

ระหว่างลาก แสดงหัวสายตามตัวชี้และเส้นประจากอีกปลายที่เสียบแล้วเพื่อช่วยเล็ง; เมื่อปล่อยจะกลับเป็นสายสามมิติจริงในฉาก ปล่อยนอกพอร์ต หัวต่อไม่ตรง อุปกรณ์ผิดช่วง หรือพอร์ตถูกใช้ในช่วงอื่น จะคืนสภาพเดิมโดยไม่บันทึกข้อผิดพลาดลงงาน การแยกชนิดหัวตรวจจากรูปร่างตัวเชื่อมต่อ เช่น RCA เสียงและภาพมีหัวแบบเดียวกัน และ LAN/HDBaseT ใช้ RJ45 ได้เหมือนกัน การเสียบเข้ากันได้จึงไม่ยืนยันว่ามีภาพ: ยังคงใช้กฎสัญญาณเดิมและแจ้งเส้นทางที่ยังไม่จำลองตามเดิม

ลากหัวที่เสียบอยู่บนโมเดลหรือจากถาดเพื่อย้ายได้ ปุ่มถอดหัวต้นทาง/ปลายทางถอดเฉพาะด้านนั้น ส่วนปุ่มถอดสายช่วงนี้ถอดทั้งสองด้าน คลิก/แตะหัวสายแล้วคลิก/แตะพอร์ตเป็นทางเลือกสำหรับจอสัมผัสและคีย์บอร์ด (เลือกพอร์ตจากรายการครบเดิมได้) Escape ยกเลิก การสลับโหมด สาย หรือโจทย์ยกเลิกการลากที่ค้างอยู่ โหมดจัดวางปิดการต่อสายเพื่อไม่ให้ลากเครื่องสับสนกับลากหัวต่อ

ข้อมูลหัวสายใช้ sourcePortId/sinkPortId/cableId เดิม ไม่มีการเปลี่ยน schema JSON งานเดิมเปิดได้ และบันทึกงานที่เสียบเพียงด้านเดียวได้เช่นเดียวกับงานครบสองด้าน ไม่เพิ่มคะแนน และไม่เปลี่ยนกฎของยูสเคส 2


## แผงควบคุมแบบย่อและผลลัพธ์ด้านบน

แผงขวาไม่มีรายการเลือกช่วงสายและปุ่มเลือกอินพุต/เอาท์พุตอีกต่อไป เลือกชนิดสายแล้วใช้หัวสายสองด้านเสียบพอร์ต ระบบหาเส้นทางของโจทย์จากอุปกรณ์ที่เสียบจริง รองรับเริ่มจากสายใดก่อน รวมทั้งเริ่มเสียบด้านจอก่อนแหล่งภาพ เมื่อครบทั้งสองด้านจะเตรียมตำแหน่งสำหรับสายที่ยังไม่ต่อให้อัตโนมัติ เลือกสายเดิมโดยคลิกสาย/หัวบนฉาก หรือเลือกพอร์ตที่เสียบอยู่จากรายการคีย์บอร์ด

ผลจากปุ่มตรวจภาพและข้อผิดพลาดชนิดหัวต่อแสดงในกรอบตรงกลางด้านบน เหนือเครื่องมือและฉาก ไม่มีผลลัพธ์ซ้ำในแผงขวา ข้อผิดพลาดและผลตรวจค้างจนกดปิดหรือเริ่มเปลี่ยนข้อมูลเพื่อไม่ให้ผลเก่าคลาดเคลื่อนกับงานใหม่ ข้อความแนะนำทั่วไปหมดเวลา 6.5 วินาที เปลี่ยนชนิดสายที่ไม่ตรงกับพอร์ตเดิมจะปฏิเสธและคงสายเดิมไว้ แสดงเหตุผลให้ถอดหัวก่อนเปลี่ยนชนิด
