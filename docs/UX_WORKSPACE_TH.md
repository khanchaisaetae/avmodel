# UX/UI ยูสเคส 3 และ 5

ปรับพื้นที่ทำงานตามหน้าที่และให้การเปลี่ยนกิจกรรมเหมือนกันทุกหน้า ใช้โมดูลกลางแทนสร้างตัวควบคุมซ้ำในแต่ละยูสเคส

## การเปลี่ยนหน้าจอ

| หน้า | แผงทำงาน |
| --- | --- |
| 3 เขียนผัง | ตรวจผัง / เหตุผล / ไฟล์ |
| 5 แก้ปัญหาภาพ | ผลภาพ / บันทึกตรวจ / รายงาน |

- ทุกยูสเคสใช้แถบปุ่มแบบยูสเคส 1: สำรวจพอร์ต / จำลองการเชื่อมต่อ / เขียนผังระบบ / แก้ปัญหาภาพ (ยูสเคส 1 → 4 → 3 → 5) เรียงลำดับเหมือนกัน ใช้สีแสดงหน้าที่กำลังเปิด ไม่มีดรอปดาวน์เลือกกิจกรรม รูปแบบร่วมอยู่ใน src/activity-nav.css ยูสเคส 2 ถูกนำออกแล้ว ลิงก์เดิมที่มี mode จะเปิดหน้าสำรวจพอร์ต ส่วนโค้ด lesson ที่ยูสเคส 5 ใช้ร่วมกันยังคงอยู่
- สายและอุปกรณ์ที่เลือกมีแผงแก้ไขเหนือผัง แสดงเฉพาะรายการที่เลือก ปิดได้ ไม่แสดงตัวเลือกพอร์ตซ้ำในแผงเลือกสาย
- ปุ่ม IN / OUT เปิด/ปิด ส่งภาพ SOURCE และ Input ยังอยู่บนอุปกรณ์ ใช้รายการพอร์ตครบตามข้อมูลอ้างอิง
- ลดคำแนะนำซ้ำ แสดงสิ่งที่ควรทำต่อในหัวผังหรือเหนือปุ่มยืนยัน เงื่อนไขจำลองและไฟล์อยู่ในส่วนรอง
- แยกเอกสารออกจากผลทดลอง แผงด้านขวาเลื่อนภายในบนจอใหญ่ ปุ่มหลักอยู่ตำแหน่งคงที่
- แท็บรองรับปุ่มลูกศร Home/End มี aria-selected/aria-controls และซ่อนแผงที่ไม่ได้เลือกจากคีย์บอร์ด

## การมองผัง

ปุ่ม “พอดีจอ” ปรับให้เห็นอุปกรณ์และป้ายสายทั้งหมดตามขอบเขตที่ใช้งานจริง มีปุ่มย่อ/ขยายและแสดงเปอร์เซ็นต์ การซูมเป็นมุมมอง ไม่แก้ตำแหน่งที่บันทึก

“จัดเรียงอุปกรณ์” ย้ายเฉพาะตำแหน่งของอุปกรณ์ เป็นการแก้ไขหนึ่งครั้งที่ย้อนกลับได้ พอร์ต สาย และการตั้งค่ายังคงอยู่ การลากขณะซูมและการวาดเส้นใช้พิกัดโลกหารด้วยสัดส่วนซูม ทำให้ปลายสายตรงตำแหน่งพอร์ต

ใช้ overflow:clip ในชั้นที่ย่อภาพ เพื่อป้องกันเบราว์เซอร์เลื่อนชั้นภาพเมื่อโฟกัสปุ่มจนหัวอุปกรณ์หาย พื้นที่เลื่อนหลักยังใช้ดูผังเมื่อขยายได้

เปิดโมเดลจากหน้าผังแบบ embedded เพื่อแสดงโมเดลกับรายละเอียดพอร์ต ลดเมนูแอปและรายการโมเดลที่ซ้ำกับหน้าหลัก ปิดแล้วกลับผังได้

## ข้อมูลและขอบเขต

ใช้ข้อมูลพอร์ต โมเดล กฎตรวจสัญญาณ รูปแบบ JSON และคีย์บันทึกงานเดิม ไม่มีคะแนนเพิ่มเติม ยูสเคส 1/2 ใช้หน้าหลักเดิม ยกเว้นรูปแบบฝังโมเดลที่เปิดจากหน้าผัง

บนจอเล็กแผงเรียงต่อกัน และใช้ปุ่มซูมเพื่อขยายพอร์ตที่ต้องเลือก ผังและรายงานยังดาวน์โหลดในแผงไฟล์ได้

## โมดูลและการตรวจ

- `workspace-ui.mjs`: เมนูกิจกรรมและแท็บที่ใช้ร่วมกัน
- `editor-workspace.mjs`: แผงของตัวแก้ไขผัง มุมมอง และแผงรายการที่เลือก
- `lesson-workspace.mjs`: การจัดแผงยูสเคส 5
- `workspace-geometry.mjs`: ขอบเขตภาพ การคำนวณซูม และตำแหน่งจัดเรียง
- `workspace.css`: รูปแบบที่ใช้ร่วมกันและ media queries

ทดสอบการคำนวณภาพและพิกัดร่วมกับชุดทดสอบเดิม ตรวจในเบราว์เซอร์ทั้ง 2 หน้า: การเปลี่ยนกิจกรรม แท็บด้วยคีย์บอร์ด ผัง 5 อุปกรณ์พอดีจอ เส้นตรงพอร์ตหลังซูม การลากขณะย่อ การเลือกสาย การยืนยันผล และการดูโมเดลในหน้าต่างฝัง
