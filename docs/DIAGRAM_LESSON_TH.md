# ยูสเคส 3 · เขียนผังระบบสัญญาณภาพ

รุ่นเริ่มใช้งาน 24 ตุลาคม 2026 — ไม่มีการให้คะแนน

เปิด `diagram.html` หรือเมนู “เขียนผังระบบ” จากหน้าหลัก

## กิจกรรม

เริ่มจากพื้นที่ว่าง เลือกโจทย์ เพิ่มอุปกรณ์ด้วยปุ่มทางซ้าย เลือกเอาท์พุตพอร์ตของแหล่งภาพ แล้วเลือกอินพุตพอร์ตของอีกอุปกรณ์เพื่อสร้างเส้น (เริ่มจากปลายรับก่อนได้) คลิกสายแล้วเลือกชนิดสายจาก Dropdown ตั้งค่าเครื่องจากตัวอุปกรณ์ และเขียนเหตุผลประกอบ

- มีโจทย์เดิม 18 โจทย์แบบ 2–4 อุปกรณ์ เพิ่มผังอิสระและกิจกรรมวิเคราะห์ข้อจำกัดของ Vertex
- เลือกอุปกรณ์ทั้ง 5 ชนิดได้ แต่โจทย์ที่ระบุอุปกรณ์จะเตือนเมื่อเพิ่มเกินหรือขาด
- กลุ่ม IN/OUT รวมพอร์ตครบตามข้อมูลอ้างอิง รวมช่องข้อมูล เสียง และพอร์ตตามโหมด ไม่ซ่อนตัวเลือกที่ไม่เหมาะสม
- ลากแถบชื่ออุปกรณ์เพื่อย้าย หรือใช้ปุ่มลูกศรบนแผงรายการที่เลือก/แป้นพิมพ์
- ดูโมเดล 3 มิติผ่านหน้าต่างสำรวจอุปกรณ์เดิม ไม่มีการแก้ข้อมูลพอร์ตหรือจุดที่ตรวจรับ
- ลบสาย ลบอุปกรณ์พร้อมสาย ย้อนกลับและทำซ้ำได้
- ตรวจผังเมื่อต้องการ ผลตรวจซ่อนเมื่อแก้ผัง ไม่มีคะแนน ไม่มีการส่งคำตอบหรือเหตุผลไปยังเซิร์ฟเวอร์

## ขอบเขตการตรวจ

ตรวจพอร์ตและสายรายช่วง ความขัดแย้งจากการใช้พอร์ตซ้ำ อุปกรณ์ที่โจทย์ต้องใช้ และโครงสร้างเส้นทางตามเงื่อนไข รองรับชื่อพอร์ตปลายทางที่ต่างกันได้หากเข้ากันได้ ไม่ตรวจตำแหน่งจัดวางเทียบกับภาพคำตอบ

ใช้กฎจำลองสัญญาณภาพเดิม: HDMI ที่มีข้อมูลรองรับ, Dell ส่งภาพภายนอก, Blu-ray เล่น/ส่งภาพ, Input ของจอ, CAMERA/HDMI IN ของ Vertex ไม่แปลง HDMI ข้าม RGB/VGA เส้นทางอื่นแสดงว่ายังไม่จำลอง ไม่ตัดสินว่าผิด

โจทย์หลายแหล่งภาพใช้ตัวเลือกแหล่งภาพสำหรับทดลองทีละแหล่ง การมีภาพแหล่งหนึ่งไม่หมายความว่าผังครบทุกเงื่อนไข จึงแสดงผลตรวจโครงสร้างและภาพแยกกัน

ผังอิสระตรวจสายรายช่วง ยังไม่ยืนยันภาพทั้งระบบ กิจกรรมวิเคราะห์ข้อจำกัดอนุญาตให้สรุปว่าทำไม่ได้โดยไม่ต้องสร้างผังที่ผิด

## การเก็บงานและส่งออก

เก็บผังพร้อมอุปกรณ์ พอร์ต สาย การตั้งค่า ตำแหน่ง และเหตุผลใน localStorage โดยแยกแต่ละโจทย์ (`av-port-lab.diagram.v1.<taskId>`) เก็บในเบราว์เซอร์เครื่องที่ใช้ หากล้างข้อมูลหรือเปลี่ยนเครื่องต้องมีไฟล์สำรอง

ดาวน์โหลด JSON เพื่อเปิดแก้ไขภายหลัง/อีกเครื่องได้ นำเข้าต้องยืนยันก่อนแทนที่ฉบับในโจทย์นั้น ตรวจรูปแบบไฟล์ อุปกรณ์ พอร์ต ตำแหน่ง และชนิดสายก่อนรับเข้า รองรับไฟล์สูงสุด 1 MB

ดาวน์โหลดภาพ SVG หรือใช้พิมพ์/บันทึก PDF จากเบราว์เซอร์ได้ ภาพส่งออกประกอบด้วยผัง ชื่อพอร์ต สาย การตั้งค่า และเหตุผล ไม่รวมคะแนนหรือผลประเมินของอาจารย์

## การตรวจสอบ

ทดสอบโมเดลข้อมูลทั้งผังว่าง การส่งออก/นำเข้า โครงสร้าง 4 อุปกรณ์ พอร์ตทางเลือก การใช้พอร์ตซ้ำ สายที่ยังไม่จำลอง วงจร และข้อความใน SVG ทดสอบหน้าเว็บสร้าง Dell → Epson ด้วย HDMI2 ที่ผู้เรียนเลือกเอง เปิดเครื่อง/ส่งภาพและ Input แล้วตรวจพบภาพตรงเป้าหมาย ย้ายอุปกรณ์ด้วยแป้นพิมพ์และโหลดผังพร้อมเหตุผลกลับจากเบราว์เซอร์ได้

## ปรับปรุงการส่งออก

ส่งออกเหตุผลครบทุกบรรทัดตามข้อความในผัง ไม่ตัดเหลือ 6 บรรทัด ตัดบรรทัดตามกลุ่มอักขระเพื่อรักษาสระและวรรณยุกต์ภาษาไทย จัดขนาดภาพตามเนื้อหา พอร์ตและชื่อสายยาวขึ้นบรรทัดใหม่ได้ กิจกรรมวิเคราะห์ข้อจำกัดแสดงข้อสรุปพร้อมเหตุผลในภาพด้วย

การพิมพ์/PDF ใช้หน้าผังแยกจากหน้าเหตุผล เพื่อให้ข้อความยาวไหลต่อหน้าถัดไปได้ โดยไม่ย่อทั้งหมดให้เล็กหรือซ่อนข้อความท้าย ผลตรวจและคะแนนไม่ถูกเพิ่มในไฟล์ส่งออก
