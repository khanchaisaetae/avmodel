# ยูสเคส 5 · แก้ปัญหาภาพ

เปิด `troubleshoot.html` เพื่อฝึกสังเกตอาการ ตรวจจากแหล่งภาพผ่านพอร์ตและสายไปยังจอ แก้ไขระบบ แล้วบันทึกหลักฐาน ไม่มีคะแนนหรือการประเมินข้อความอัตโนมัติ

## สถานการณ์

| รหัส | ระบบ | อาการ / ประเด็นสำหรับผู้สอน |
| --- | --- | --- |
| UC5-01 | Dell → Epson | จอปิด |
| UC5-02 | Dell → Sony TV | ต้นทางไม่ส่งภาพออกจอ |
| UC5-03 | Blu-ray → Epson | เลือก Input ไม่ตรงสาย |
| UC5-04 | Blu-ray → Sony TV | ยังไม่เล่น / ส่งภาพ |
| UC5-05 | Dell → Epson | สายยังไม่เชื่อมต่อ |
| UC5-06 | Dell → Sony TV | เลือกชนิดสายไม่ตรงกับพอร์ตในผัง |
| UC5-07 | Blu-ray → Epson | ใช้ HDMI OUT 2 ซึ่งส่งเฉพาะเสียง |
| UC5-08 | Dell → Vertex → Epson | อุปกรณ์กลางปิด |
| UC5-09 | Dell → Vertex → Sony TV | ได้ภาพกล้องแทนภาพ Dell |
| UC5-10 | Blu-ray → Vertex → Epson | เลือก RGB แต่ใช้ HDMI OUT |
| UC5-11 | Dell และ Blu-ray → Sony TV | สายสองเส้นใช้ Input เดียวกัน |
| UC5-12 | Dell → Vertex → Epson | จอปิดและ Dell ไม่ส่งภาพ ต้องแก้มากกว่าหนึ่งจุด |

ชื่อและอาการในหน้าเรียนไม่เฉลยสาเหตุในตารางนี้ คำใบ้เปิดเมื่อผู้เรียนขอ 3 ระดับ: แนวตรวจทั่วไป → กลุ่มที่ควรตรวจ → ผลวินิจฉัยปัจจุบันจากกฎจำลอง ไม่ชี้จุดผิดอัตโนมัติเหมือนโหมดฝึกยูสเคส 2

## การใช้งาน

1. สังเกตภาพจริงในพื้นที่จำลอง และสถานะปุ่มบนอุปกรณ์
2. เลือกหมวดจุดที่ตรวจ เขียนสิ่งที่พบอย่างน้อย 3 ตัวอักษร แล้วบันทึกผลตรวจ (สูงสุด 30 รายการ)
3. ปรับพอร์ต สาย เปิด/ปิดเครื่อง เปิดส่งภาพหรือเล่นสื่อ SOURCE และ Input จากตัวอุปกรณ์บนผัง
4. สรุปสาเหตุและวิธีแก้อย่างน้อย 10 ตัวอักษร กดยืนยันเมื่อภาพตรงเป้าหมาย
5. ดาวน์โหลดรายงาน JSON หรือเลือกสถานการณ์ถัดไป

ระบบตรวจว่ามีภาพจากแหล่งที่โจทย์ต้องการ สายครบตามระบบ ไม่มีพอร์ตซ้ำ และมีบันทึกกับข้อความสรุป **ความยาวข้อความไม่ใช่การตรวจความถูกต้องของเหตุผล** ผู้สอนต้องตรวจเนื้อหาเอง ผู้เรียนบันทึกผลตรวจได้ก่อนหรือหลังแก้ระบบ

การเปลี่ยนสาย การตั้งค่า บันทึกผลตรวจ หรือข้อความสรุปหลังยืนยัน ต้องยืนยันใหม่เมื่อพร้อม ปุ่มย้อนกลับใช้กับการเปลี่ยนสถานะระบบและรายการตรวจ การพิมพ์ข้อความสรุปไม่สร้างประวัติทุกตัวอักษร เริ่มใหม่คืนสภาพปัญหาเดิมและล้างบันทึกของรอบนั้น

## กฎร่วม

ใช้พอร์ตที่ยืนยันใน `data/port-catalog.json`, กฎ `scenario-engine.mjs`, `connection-rules.mjs` และรายการสายร่วมกับยูสเคสอื่น ให้สำรวจพอร์ต IN/OUT ได้ครบ ไม่ซ่อนพอร์ตที่ไม่ได้ใช้ สายเลือกจาก dropdown บนเส้นในผัง

Vertex ไม่แปลง HDMI ↔ RGB/VGA ไม่มี Matrix หรือโจทย์แสดงพร้อมกันสองจอ HDMI OUT 2 ของ Blu-ray ใช้ส่งภาพไม่ได้ USB-C ของ Dell ส่งภาพได้ แต่เส้นทางอะแดปเตอร์ที่ยังไม่จำลองยังไม่ถูกตัดสินว่าเชื่อมต่อผิดหรือผ่านจากการเดา

## รายงานและการเก็บข้อมูล

- `av-port-lab.troubleshoot-progress.v1`: รหัสสถานการณ์ที่เคยยืนยันสำเร็จ แยกจากยูสเคสอื่น
- `av-port-lab.troubleshoot-report.v1`: รายงานล่าสุดเมื่อเริ่มบันทึกผลตรวจหรือข้อความสรุป มีลำดับการตรวจ เวลา ภาพขณะตรวจ การตั้งค่า เหตุผล จำนวนคำใบ้ และผลตรวจปัจจุบัน ไม่มีคะแนน
- สถานะขณะฝึกเริ่มใหม่เมื่อโหลดหน้า รายงานครั้งก่อนยังดาวน์โหลดได้ก่อนเริ่มบันทึกใหม่
- ไม่มีบัญชีผู้เรียนหรือการส่งผลให้อาจารย์อัตโนมัติ ดาวน์โหลดก่อนเปลี่ยนโจทย์เพื่อเก็บรายงานแต่ละข้อ
- ผลเป็นการจำลอง ไม่ใช่การตรวจสัญญาณไฟฟ้าหรือสภาพสายจริง ไม่จำลอง EDID, HDCP หรือความเสียหายฮาร์ดแวร์

## โมดูล

- `troubleshoot-catalog.mjs`: ข้อมูลสถานการณ์และหมวดจุดตรวจ
- `troubleshoot-model.mjs`: สภาพปัญหาตั้งต้น บันทึกหลักฐาน เงื่อนไขยืนยัน คำใบ้ และรายงาน ไม่มี DOM
- `troubleshoot-activity.mjs`: แผงตรวจปัญหา การบันทึก/ดาวน์โหลดรายงาน และการเชื่อมตัวควบคุมร่วม
- `troubleshoot.css`: สไตล์ของแผงตรวจปัญหา
- `port-lab.mjs` เลือก activity จากหน้า ส่วนโมดูล `lesson-*` ใช้ร่วมกัน ค่าเริ่มต้นยูสเคส 2 คงเดิม

ทดสอบ `node --test tests/troubleshoot.test.mjs` และชุดทดสอบทุกยูสเคสเพิ่มเติมก่อนเผยแพร่
