## วิธีฝึก

1. กด “ฝึกเชื่อมต่อ” แล้วเลือกโจทย์ แถบอุปกรณ์แสดงเฉพาะเครื่องที่ใช้ในข้อนั้น
2. เลือกช่วงสายก่อนเลือกพอร์ตจากโมเดลหรือรายการชื่อพอร์ต เลือกสายแล้วกด “เชื่อมช่วงนี้” ให้ครบทุกช่วง
3. เปิดเครื่อง ส่งภาพจาก Dell หรือเริ่มเล่นสื่อ Blu-ray และตั้ง SOURCE ของ Vertex กับ Input ของจอให้ตรงเส้นทาง
4. กด “ตรวจภาพตามเป้าหมาย” อ่านผลและแก้ไขได้ จำนวนครั้งเป็นตัวนับ ไม่ใช่คะแนนสอบ
5. ข้อที่มีสองแหล่งภาพต้องตรวจภาพแรกสำเร็จ แล้วกดเป้าหมายถัดไป สลับ Input และตรวจแหล่งที่สองโดยไม่ถอดสาย จึงสำเร็จครบโจทย์

ผังอัตโนมัติแสดงพอร์ตและสายทุกช่วง พร้อมสัญลักษณ์ปลายสายที่ตำแหน่งบนโมเดลที่กำลังดู ผลจำลองแยก “ไม่มีภาพ”, “มีภาพแต่ผิดแหล่ง”, “ภาพถูกแต่ยังต่อระบบไม่ครบ” และ “สำเร็จครบโจทย์” ตรวจพอร์ตซ้ำที่ถูกใช้งานแล้วและไม่อนุญาต HDMI OUT 2 ของ Blu-ray ซึ่งส่งเฉพาะเสียง

เปลี่ยนพอร์ตหรือชนิดสายต้องเชื่อมช่วงนั้นใหม่ และล้างผลตรวจแหล่งภาพในรอบปัจจุบันเพื่อให้ตรวจซ้ำทั้งสองแหล่งหลังเปลี่ยนสาย สถานะสายและเครื่องคงไว้เมื่อสลับโจทย์ในหน้าเดียวกัน รีโหลดแล้วเริ่มการต่อใหม่ ประวัติรหัสโจทย์ที่สำเร็จเก็บใน localStorage ของเบราว์เซอร์นี้จนกดเริ่มโจทย์นั้นใหม่ ไม่เก็บข้อมูลส่วนบุคคลหรือส่งผลฝึกไปภายนอก

## เป้าหมายการเรียนรู้

- แยกแหล่งกำเนิด ตัวส่งผ่าน และอุปกรณ์แสดงผล รวมถึงพอร์ต IN / OUT
- เลือกพอร์ตและสายครบแต่ละช่วงโดยไม่ใช้ช่อง Input ร่วมกัน
- ติดตามว่าภาพที่ปรากฏมาจากแหล่งใด และตั้ง SOURCE / Input ให้ตรงเป้าหมาย
- สลับสองแหล่งภาพโดยไม่ถอดสาย และอธิบายผังจากการเชื่อมต่อของตนได้

## ข้อเท็จจริงและเงื่อนไขจำลอง

ข้อมูลพอร์ตมาจาก data/port-catalog.json และตำแหน่งจาก data/model-mappings.json ที่ผู้ใช้ตรวจรับแล้ว ไม่แก้สเปกหรือพิกัดเดิม กฎ Vertex ตามคำยืนยันผู้ใช้บันทึกแยกใน docs/VERTEX_ROUTING_TH.md

โจทย์เดิม 2-01 กำหนด 1280×800 ที่ 60 Hz ส่วนโจทย์เพิ่มกำหนด 1920×1080 ที่ 60 Hz ให้แหล่งภาพ Vertex และสาย HDMI ในชุดฝึกรองรับรูปแบบนี้และสายสภาพดี เป็นเงื่อนไขของบทเรียน ไม่ใช่การเพิ่มสเปกยืนยันให้เครื่องจริง รูปแบบที่ปลายทางมีข้อมูลรองรับไม่ครบจะไม่ตัดสินเป็นความผิดของผู้เรียน

เส้นทางคำตอบที่จำลองใช้ HDMI โดยตรง: Dell HDMI, Blu-ray HDMI OUT 1 (VIDEO/AUDIO), Vertex HDMI IN / OUT และ HDMI ของจอทั้งสองช่อง ต้องเลือก Input ตามช่องที่เสียบ ส่วน USB-C ของ Dell ส่งภาพได้ผ่านสายหรืออะแดปเตอร์ที่รองรับ แต่ยังไม่จำลองเส้นทางนี้ รวมถึง USB Display, HDBaseT, EDID/HDCP และการแปลงสัญญาณ จึงไม่ตัดสินว่า USB-C ส่งภาพไม่ได้

ภาพเป็นผลจำลอง ไม่ใช่สัญญาณไฟฟ้าจริง ปลายสายเป็นสัญลักษณ์ ไม่ใช่รูปทรงหัวต่อจริง ผังสร้างจากตัวเลือกของผู้เรียน ยังไม่ใช่เครื่องมือเขียนผังอิสระของยูสเคส 6 และยังไม่ครบทั้ง 7 ยูสเคส

## การตรวจสอบ

- tests/scenario-engine.test.mjs ตรวจครบ 18 โจทย์และทั้งสองแหล่งภาพ รวมกรณีผิดแหล่ง, SOURCE ของ Vertex ผิดประเภท, Input ผิด, สายไม่ครบ, พอร์ตซ้ำ, ช่องเสียง, USB-C ที่ยังไม่จำลอง และการไม่เปลี่ยน catalog
- คงชุดตรวจเดิมของ connection-exercise, connection-rules และข้อมูลพอร์ต/โมเดลทั้งหมด
- ทดสอบผ่านเบราว์เซอร์เรื่องเลือกโจทย์ ช่วงสาย การเปิดเครื่อง SOURCE / Input การแสดงภาพผิดแหล่งและสำเร็จครบสองแหล่ง
- เบราว์เซอร์ทดสอบใช้ Canvas สำรองเพราะสร้าง WebGL context ไม่ได้ จึงยังไม่ยืนยันประสิทธิภาพ WebGL บนเครื่องผู้เรียน

```sh
node --test tests/*.test.mjs
```
