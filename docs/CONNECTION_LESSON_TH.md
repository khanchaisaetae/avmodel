## วิธีฝึกในโต๊ะทดลอง

หน้าใหม่ใช้ผังระบบเป็นพื้นที่หลัก เห็นอุปกรณ์ทุกตัวเพียงครั้งเดียวและตำแหน่งคงที่ เป้าหมายปัจจุบันแสดงตลอดเวลา แยกเป็น 3 ขั้นที่ย้อนกลับได้:

1. **ต่อสาย**: เลือกอุปกรณ์หรือหมายเลขสาย เลือกพอร์ต OUT / IN และชนิดสาย กดต่อสายทีละเส้น มีจำนวนสายที่ต่อครบแล้วเป็นข้อความ
2. **ตั้งค่าเครื่อง**: คลิกอุปกรณ์บนผังหรือแท็บชื่อเครื่อง แผงด้านขวาแสดงเฉพาะเครื่องนั้น เปิดเครื่อง ส่งภาพ และเลือก SOURCE / Input ให้ตรงกับช่องที่เสียบ
3. **ทดลองภาพ**: ดูภาพจำลองบนอุปกรณ์แสดงผล แล้วกดทดลองตามเป้าหมาย ข้อสองแหล่งภาพต้องแสดงทั้งสองแหล่งโดยไม่ถอดสายจึงครบโจทย์

เส้นประคือยังไม่ต่อ เส้นทึบสีเทาคือต่อสายแล้ว สีเขียวอมฟ้าคือเส้นทางที่กำลังแสดงภาพจริง มีลูกศรและข้อความประกอบ สีอำพันแจ้งภาพผิดแหล่งหรือจุดตรวจ เมื่อ Vertex อยู่ CAMERA จะเน้นเฉพาะสายขาออกของ Vertex ไม่แสดงว่าสัญญาณไหลมาจาก Dell ภาพบนจอแยกเป็นหน้าสไลด์ Dell, วิดีโอ Blu-ray และเอกสารจากกล้อง Vertex ทั้งหมดเป็นภาพจำลองตามกฎบทเรียน

กด “ดูพอร์ตบนเครื่อง” เพื่อเปิดโมเดล GLTF จริงในหน้าต่าง เลือกพอร์ตบนโมเดลหรือจากชื่อแล้วกลับมาผังเดิม ปิดด้วยปุ่มหรือ Escape ได้ ค่าเริ่มต้นแสดงเฉพาะพอร์ตที่มีข้อมูลความสามารถภาพยืนยัน และมี “ดูพอร์ตทั้งหมด” โดยไม่ใช้สีหรือภาพหัวต่อสมมติแทนหลักฐานสเปก ทิศทางภาพของ USB-C ใช้ video_direction แยกจากทิศทางข้อมูล USB

ผลตรวจแยก “ไม่มีภาพ”, “มีภาพแต่ผิดแหล่ง”, “ภาพถูกแต่สายไม่ครบ” และ “สำเร็จครบโจทย์” มีปุ่ม “ไปตรวจจุดนี้” เพื่อกลับไปยังเครื่องหรือสายที่เกี่ยวข้องและเปิดอ่านเหตุผลเพิ่มได้ ไม่เลือกพอร์ตหรือ Input ที่ถูกต้องให้เอง

มีการย้อนการกระทำล่าสุดได้สูงสุด 40 การกระทำต่อโจทย์ในหน้าปัจจุบัน และยืนยันก่อนเริ่มโจทย์ใหม่ เปลี่ยนพอร์ตหรือชนิดสายต้องต่อช่วงนั้นใหม่และล้างผลตรวจแหล่งภาพในรอบปัจจุบัน สถานะคงไว้เมื่อสลับโจทย์ในหน้าเดียวกัน รีโหลดแล้วเริ่มการต่อใหม่ ประวัติรหัสโจทย์สำเร็จเก็บใน localStorage จนเริ่มโจทย์นั้นใหม่ ไม่เก็บข้อมูลส่วนบุคคลหรือส่งผลฝึกออกภายนอก

หน้าจอแคบจัดแผงควบคุมไว้ใต้ผัง พร้อมปุ่มกลับไปดูผัง หมายเลขสายใช้ปุ่มขนาดกะทัดรัดและแสดงรายละเอียดในแผงต่อสาย รูปอุปกรณ์บนผังเป็นภาพประกอบ ไม่แทนตำแหน่งพอร์ตจริงที่ตรวจรับบนโมเดล

## เป้าหมายการเรียนรู้

- แยกแหล่งกำเนิด ตัวส่งผ่าน และอุปกรณ์แสดงผล รวมถึงพอร์ต IN / OUT
- เลือกพอร์ตและสายครบแต่ละช่วงโดยไม่ใช้ช่อง Input ร่วมกัน
- ติดตามว่าภาพที่ปรากฏมาจากแหล่งใด และตั้ง SOURCE / Input ให้ตรงเป้าหมาย
- สลับสองแหล่งภาพโดยไม่ถอดสาย และอธิบายผังจากการเชื่อมต่อของตนได้

## ข้อเท็จจริงและเงื่อนไขจำลอง

ข้อมูลพอร์ตมาจาก data/port-catalog.json และตำแหน่งจาก data/model-mappings.json ที่ผู้ใช้ตรวจรับแล้ว ไม่แก้สเปกหรือพิกัดเดิม กฎ Vertex ตามคำยืนยันผู้ใช้บันทึกแยกใน docs/VERTEX_ROUTING_TH.md

โจทย์เดิม 2-01 กำหนด 1280×800 ที่ 60 Hz ส่วนโจทย์เพิ่มกำหนด 1920×1080 ที่ 60 Hz ให้แหล่งภาพ Vertex และสาย HDMI ในชุดฝึกรองรับรูปแบบนี้และสายสภาพดี เป็นเงื่อนไขของบทเรียน ไม่ใช่การเพิ่มสเปกยืนยันให้เครื่องจริง รูปแบบที่ปลายทางมีข้อมูลรองรับไม่ครบจะไม่ตัดสินเป็นความผิดของผู้เรียน

เส้นทางคำตอบที่จำลองใช้ HDMI โดยตรง: Dell HDMI, Blu-ray HDMI OUT 1 (VIDEO/AUDIO), Vertex HDMI IN / OUT และ HDMI ของจอทั้งสองช่อง ต้องเลือก Input ตามช่องที่เสียบ ส่วน USB-C ของ Dell ส่งภาพได้ผ่านสายหรืออะแดปเตอร์ที่รองรับ แต่ยังไม่จำลองเส้นทางนี้ รวมถึง USB Display, HDBaseT, EDID/HDCP และการแปลงสัญญาณ จึงไม่ตัดสินว่า USB-C ส่งภาพไม่ได้

ภาพเป็นผลจำลอง ไม่ใช่สัญญาณไฟฟ้าจริง ปลายสายเป็นสัญลักษณ์ ไม่ใช่รูปทรงหัวต่อจริง ผังสร้างจากตัวเลือกของผู้เรียน ยังไม่ใช่เครื่องมือเขียนผังอิสระของยูสเคส 6 และยังไม่ครบทั้ง 7 ยูสเคส
