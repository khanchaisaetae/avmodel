# ยูสเคส 2: เชื่อม Dell G7 7588 ไปยัง Epson EB-2165W

## สิ่งที่ทำได้

กด “ฝึกเชื่อมต่อ” ที่แถบบน เพื่อเข้าภารกิจแรก เลือกพอร์ตจากช่องต่อจริงบนโมเดลหรือรายการชื่อพอร์ต แสดงอุปกรณ์ทีละเครื่อง สลับ Dell/Epson ได้ โดยเก็บตัวเลือกต้นทางและปลายทางไว้พร้อมกัน

1. เลือกพอร์ตต้นทาง Dell และปลายทาง Epson
2. เลือกสาย HDMI, VGA หรือ USB-A → USB-B แล้วกด “เชื่อมสาย”
3. เปิด Dell และ Epson เปิดส่งภาพออกจอภายนอก และเลือก Input ของ Epson
4. กดตรวจผล อ่านคำอธิบายและแก้ไขได้ จำนวนครั้งเป็นตัวนับการตรวจ ไม่ใช่คะแนนสอบ
5. เมื่อครบเงื่อนไข แสดงภาพทดสอบจำลอง ผังที่ระบุชื่อพอร์ตและสาย พร้อมปลายสายสีเขียวที่ตำแหน่งบนโมเดล

ถอดสายได้ เปลี่ยนพอร์ตหรือชนิดสายแล้วต้องเชื่อมใหม่ กดเริ่มกิจกรรมใหม่เพื่อล้างการเลือกและสถานะเครื่อง ย้ายกลับ “สำรวจพอร์ต” เพื่อดูอุปกรณ์ครบ 5 ตัวและเอกสารตามเดิม ผลการฝึกอยู่ในหน่วยความจำของหน้าปัจจุบัน รีโหลดแล้วเริ่มใหม่ ไม่ส่งข้อมูลผู้เรียนออกภายนอก

## เป้าหมายการเรียนรู้

- แยกพอร์ตภาพ OUT ของแหล่งกำเนิดออกจากพอร์ต IN ของอุปกรณ์แสดงผล
- เลือกสายตามหัวต่อและชนิดสัญญาณ
- แยกการต่อสายถูกออกจากการเปิดเครื่อง ส่งภาพ และเลือก Input ถูก
- อธิบายผัง Dell HDMI OUT → สาย HDMI → Epson HDMI1/MHL หรือ HDMI2 ได้

## ขอบเขตข้อเท็จจริงและเงื่อนไขจำลอง

ข้อมูลความสามารถพอร์ตมาจาก data/port-catalog.json และตำแหน่งจาก data/model-mappings.json ที่ผู้ใช้ตรวจรับครบแล้ว กิจกรรมไม่แก้สเปกหรือพิกัดเดิม

โจทย์กำหนดให้ Dell และสายภาพในชุดฝึกรองรับ 1280×800 ที่ 60 Hz และสายสภาพดี การตั้งค่านี้เป็นข้อมูลของสถานการณ์ฝึกในหน่วยความจำ ไม่ใช่หลักฐานเพิ่มเติมว่า Dell รองรับรูปแบบภาพทุกรูปแบบ ไม่เขียนกลับไปที่ catalog ส่วน Epson มีรูปแบบนี้ในรายการที่ตรวจจากคู่มือแล้ว

เส้นทางที่ฝึกสำเร็จในภารกิจแรกคือ Dell HDMI → HDMI ของ Epson ผ่านสาย HDMI โดยใช้กฎ native direct video ที่มีอยู่ USB-C ของ Dell ส่งภาพได้ตามหลักฐาน แต่กิจกรรมนี้ยังไม่จำลองอะแดปเตอร์ DisplayPort over USB-C จึงให้คำอธิบายว่าอยู่นอกขอบเขต ไม่ตัดสินว่า USB-C ส่งภาพไม่ได้ ส่วน USB Display, พอร์ตเปลี่ยนโหมด และ HDBaseT คงข้อกำหนดเฉพาะและไม่ให้คะแนนจากข้อสันนิษฐาน

ภาพที่แสดงเป็นผลจำลองตามเงื่อนไขโจทย์ ยังไม่จำลอง EDID, HDCP, สายเสีย การแปลงสัญญาณ หรือสัญญาณไฟฟ้าจริง ปลายสายบนโมเดลเป็นสัญลักษณ์แสดงตำแหน่งการเสียบ ไม่ได้ใช้แทนรูปทรงหัว HDMI จริง

ผังเป็นผลจากการเลือกเชื่อมต่ออัตโนมัติ ยังไม่ใช่เครื่องมือเขียนผังอิสระของยูสเคส 6 และยังไม่ใช่กิจกรรมประเมินผลทั้ง 7 ยูสเคส

## การตรวจสอบ

- tests/connection-exercise.test.mjs: 16 กรณี รวมสองช่อง HDMI ของ Epson, สายผิด, HDMI→VGA ที่ต้องแปลง, ช่องเสียง, ปิดเครื่อง, ไม่ส่งภาพ, Input ผิด, ยังไม่เสียบสาย, เปลี่ยนสายแล้วต้องเชื่อมใหม่ และไม่เขียนข้อมูลเงื่อนไขโจทย์ทับสเปก
- ทดสอบผ่านเบราว์เซอร์: เข้ากิจกรรม เลือกสองพอร์ต เลือกสายผิดแล้วแก้เป็น HDMI เปิดเครื่อง เลือก Input ผิดแล้วแก้จนสำเร็จ รวมถึงข้อความยกเว้นเส้นทาง USB-C
- ตัวแสดงผลทดสอบเป็น Canvas สำรอง เนื่องจากเบราว์เซอร์ทดสอบไม่สามารถสร้าง WebGL context ได้ ทั้งสองโหมดใช้ geometry กล้องและจุดพอร์ตเดียวกัน

```sh
node --test tests/*.test.mjs
```
