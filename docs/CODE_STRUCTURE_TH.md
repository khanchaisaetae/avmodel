# โครงสร้างโค้ด VIRTUAL AV LAB

ปรับแยกโมดูลของยูสเคสที่พัฒนาแล้วยูสเคส 1, 2, 3 และ 5 โดยคงหน้าจอ ลิงก์ ข้อมูลพอร์ต รูปแบบไฟล์ JSON และคีย์ localStorage เดิม ไม่เพิ่มระบบให้คะแนน ไม่เพิ่มเฟรมเวิร์กหรือขั้นตอน build

## ส่วนกลางและขอบเขตการพึ่งพา

- `data/port-catalog.json` และ `data/model-mappings.json` เป็นข้อมูลอ้างอิงร่วม ไม่มีสำเนาแยกตามยูสเคส
- `connection-rules.mjs`, `scenario-engine.mjs`, `scenario-catalog.mjs`, `learning-mode.mjs`, `lesson-cables.mjs`, `lesson-view.mjs`, `mapping-model.mjs` และ `software-view.mjs` ยังคงเป็นโมดูลร่วมตามหน้าที่เดิม
- ตัวควบคุมแต่ละหน้าเป็นเจ้าของสถานะ โมดูลหน้าจอรับ dependency ผ่าน factory ไม่ import ย้อนกลับมาที่ไฟล์เริ่มต้น จึงไม่มีวงจร import
- บริบท `moduleScope` ใช้ getter/setter เพื่อให้งาน async และ event handler อ่านสถานะปัจจุบันเสมอ ไม่คัดลอกค่าโมเดลหรือผังเก่าค้างไว้ในโมดูลที่แยกออกมา
- ไฟล์ module แต่ละตัวไม่มีการ mount หน้าเองตอน import จุดเริ่มต้นยังเป็น `port-lab.mjs` และ `diagram-editor.mjs`
- CSS คงแยกตามหน้าที่เดิม: `port-lab.css`, `connection-table.css`, `diagram.css` เพื่อให้รอบนี้ไม่เปลี่ยนหน้าตา
- ไม่แก้ GLTF, PDF อ้างอิง หรือข้อมูลพอร์ตที่ผู้ใช้ตรวจรับแล้ว

## การตรวจสอบ

รัน `node --test tests/*.test.mjs` จาก checkout ที่มีเอกสารอ้างอิงตาม hash ที่ยืนยัน ชุดทดสอบเพิ่มตรวจการแยกสถานะระหว่าง instance การอ่านไฟล์เก่า การเริ่มหน้ากิจกรรม API เดิม และกราฟ import ที่ไม่มีไฟล์ตกหล่น/วงจร

ตรวจในเบราว์เซอร์เพิ่มเติม: รายละเอียด HDMI ของ Dell เปลี่ยนเป็น Sony TV และพบ 12 พอร์ต, เชื่อม Dell → Epson ในยูสเคส 2 สำเร็จ, โหมดประเมินซ่อนคำแนะนำก่อนส่งและบังคับกรอกเหตุผล, กลับโหมดสำรวจได้, สร้างผังในยูสเคส 3 ตรวจภาพได้ ย้าย ย้อนกลับ ทำซ้ำ และเปิดผังที่บันทึกไว้ได้

## ยูสเคส 5 · แก้ปัญหาภาพ

`troubleshoot.html` ใช้ตัวควบคุมและโมเดลร่วมกับหน้าฝึก แยกสถานการณ์ (`troubleshoot-catalog.mjs`), กฎหลักฐาน/การยืนยัน/คำใบ้/รายงาน (`troubleshoot-model.mjs`), แผงบันทึกและดาวน์โหลด (`troubleshoot-activity.mjs`), สไตล์ (`troubleshoot.css`) ส่วนขยายเลือกปิดการชี้สาเหตุอัตโนมัติและขอคำใบ้ได้ ดู `TROUBLESHOOT_LESSON_TH.md`

## พื้นที่ทำงานร่วมของยูสเคส 3 และ 5

เพิ่ม `workspace-ui.mjs`, `editor-workspace.mjs`, `lesson-workspace.mjs`, `workspace-geometry.mjs` และ `workspace.css` เพื่อใช้เมนูกิจกรรม แท็บ พื้นที่เลือกสาย และการซูมผังร่วมกัน รายละเอียดอยู่ใน `UX_WORKSPACE_TH.md` โมดูลกฎและรูปแบบข้อมูลบันทึกเดิมยังใช้ร่วมตามเดิม

## ยูสเคส 4 · ทดลองเชื่อมต่อสามมิติ

`lab3d.html` เป็นกิจกรรมใหม่แยกจากยูสเคส 2 ใช้โมเดลและตำแหน่งพอร์ตที่ตรวจรับในฉากเดียวผ่าน `lab3d-scene.mjs` ส่วน `lab3d-app.mjs` ประสานหน้าจอ/สถานะ และ `lab3d-model.mjs` ตรวจการเลือกกับไฟล์บันทึก โดยใช้กฎสัญญาณเดิมและคีย์บันทึกแยก ดู `LAB3D_TH.md`
