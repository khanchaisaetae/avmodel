ลากซ้าย: หมุน · ล้อเมาส์: ซูม · ลากขวา: เลื่อน · คลิกพอร์ตบนเครื่องเพื่อเลือก
01 / เชื่อมต่ออุปกรณ์

ลากสายเสียบพอร์ต

เลือกสาย แล้วลากหัวด้านต้นทางและปลายทางไปที่พอร์ต หรือแตะหัวสายแล้วแตะพอร์ต ต่อสายครบแล้วเริ่มสายถัดไปได้ทันที คลิกสายบนฉากเพื่อแก้ไข

02 / ทดลองภาพ

ทดลองเปิด–ปิดเครื่อง ส่งภาพ และสลับ Input หรือ SOURCE จากตัวอุปกรณ์ แล้วสังเกตผลบนจอ

พอร์ตทั้งหมด / เลือกด้วยคีย์บอร์ด

เปิดดูหรือโฟกัสพอร์ตได้ครบตามข้อมูลอ้างอิง แตะหัวสายแล้วเลือกพอร์ตจากรายการนี้ได้

การใช้งานและข้อมูลบันทึก

เลือกชนิดสาย ลากหัวสายทั้งสองด้านจากถาดไปยังพอร์ตบนโมเดล หรือแตะหัวสายแล้วแตะพอร์ต คลิกหัวสายที่เสียบอยู่เพื่อเลือกและถอดได้ เปิดเครื่องและตั้งค่าจากแผงชื่ออุปกรณ์บนฉาก เพื่อสังเกตผลบนจอ

สายและผลภาพเป็นการจำลองตามกฎสัญญาณเดิม เส้นทางที่ยังไม่จำลองจะแจ้งว่ายังตรวจไม่ได้ ไม่มีคะแนน

เปิดหน้าและเปลี่ยนโจทย์จะเริ่มงานว่าง กด “ทำงานเดิมต่อ” เพื่อกู้คืน บันทึกเมื่อแก้ไขแยกตามโจทย์ในเบราว์เซอร์นี้ ใช้ไฟล์ JSON สำรองหรือย้ายเครื่อง
